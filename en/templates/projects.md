# Private Customer and Project Register

Status: not set up yet

Use confirmed entries only. If a customer has several projects, use a separate row and a unique key for each. The local folder is assigned again on every Mac. Repository and Jira prefix are optional, empty fields mean no value.

| Key | Customer or project | Local folder | Repository | Jira prefix | Status |
| --- | --- | --- | --- | --- | --- |

Allowed status values: active, paused, archived, to-assign.
With "to-assign" the local folder may be empty. This entry is not permission to guess a path. Clarify the assignment before storing anything. All other entries need a confirmed absolute local folder. Do not include credentials in repository addresses.

This register is not a task list. Personal tasks live in Microsoft To Do, project tickets in Jira.
