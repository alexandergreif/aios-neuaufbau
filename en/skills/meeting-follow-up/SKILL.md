# Meeting Follow-Up

Follow the [core rules](../../rules/core.md) and [storage](../../references/storage.md). The basis is notes provided by the user or an explicitly selected transcript for a specific meeting. Do not search broadly for recordings and do not start a recording. If a needed basis is missing, ask first for it or for an explicitly chosen alternative. An earlier preparation does not substantiate actual decisions.

Create a concise follow-up with decisions, open questions, your own next steps and commitments made by others as separate groups. For each statement, name the passage or source. Record owners and deadlines only when they are explicitly substantiated. A person mentioned is not automatically responsible. Unclear points remain as a need for clarification instead of being presented as a task or commitment.

Store the result according to the storage reference in the assigned project, or for a clearly personal meeting in the personal output folder. If the project assignment is unclear, clarify it. Your own tasks and possible follow-ups are suggestions only. Creating tasks, sending anything and saving lasting knowledge notes require a separate concrete task within the applicable authority. The follow-up task alone does not trigger an external write action.
