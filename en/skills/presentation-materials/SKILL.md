# Create Presentation Materials

Follow the [core rules](../../rules/core.md) and [storage](../../references/storage.md). Determine target audience, learning objective, desired output and scope from the task. Check existing original material, customer specifications and relevant project rules before reusing content. If a needed source or decision is missing, ask first about how to proceed and wait for the decision before continuing on a limited basis.

Order content by what the target audience should understand or do. Link key statements to evidence and mark examples as real and substantiated or explicitly fictional. Keep subject-matter content separate from design. Keep trainer notes separate from participant materials. Create presentation, handout and sample collection only to the requested extent and use existing design specifications whose scope of validity has been verified. An old sample is not evidence of current customer colors, figures or approvals.

Before choosing a renderer or document tool, check its actual availability and suitability. A successful file build does not replace a visual check. Check finished materials as they actually render, including long content and a narrow or printable view where the format requires it. Openly report if this check was not possible. Store results in the assigned project. The materials task does not send or publish anything.
